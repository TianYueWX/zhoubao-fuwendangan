### Build Verification(已修复,当前可用)
原始 `pnpm run build` 报三类错误,已逐项处理:
1. `tsconfig.node.json extends "@vue/tsconfig/tsconfig.node.json"` 路径不存在(@vue/tsconfig@0.7.0 只有 dom.json / lib.json / json.json,没有 node.json)
   → 重写为自包含 tsconfig(去掉 extends、composite;保留 noEmit),并从 tsconfig.json 移除 project references 数组
2. `tsconfig.json TS6310: Referenced project ... may not disable emit`(composite + noEmit 冲突)
   → 同上,干掉 references 即消失
3. `<script src="./china-geo.js">` Vite 警告需要 type="module" 但又想在 file:// 同步运行
   → 改 `<script src="/china-geo.js">`(绝对路径),Vite 直接按 public 资产拷贝不走 bundle,保留同步语义
4. 顺带修复了 vue-tsc 暴露的深层类型问题:
   - `RawRow` 未 export(被 FileDrop 引用)→ store/analysis.ts 加 `export type { RawRow }`
   - `ArchetypeResult/Archetype/ArchetypeCoreCard` 未从 archetype.ts 显式 export → 加 `export type {...}`
   - ECharts 对象字面量 `{type: 'line', ...}` 不能直接赋值给 `EChartsOption`(判别联合推断回退成 string)
     → 在 useChart.ts 定义 `ChartOptionInput = EChartsOption | Record<string, unknown>`,ChartCard 的 prop 和 4 个有图表的 Tab 的 computed 都从 `EChartsOption | null` 切到 `ChartOptionInput | null`,再在 useChart setOption 处断言回 EChartsOption
   - `noUncheckedIndexedAccess` 触发 `s.total` / `d.value[0]` / `symbolSize(v)` 等可能 undefined
     → 通过 `?? 0` fallback + 把工具函数参数标 `unknown` 再内部断言
   - `visualMap.formatter` 参数类型签名是 `OptionDataValue`(number | string | undefined),写死 `(v: number) =>` 不兼容
     → 改 `(v: unknown) => Number.isFinite(num) ? num : 0) + '%'`
5. `vite emptyOutDir` 调 `rmSync` 走沙箱 safe-delete/trash 钩子偶发 `Some operations were aborted`
   → vite.config.ts 加 `build.emptyOutDir: false`;dist 由调用方手动清。改动注释里写明原因
