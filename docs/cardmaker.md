# 卡牌工坊

入口：首页「小工具 → 卡牌工坊」；地址 `#/cardmaker`；卡库详情「以此卡制作」。

## 操作

新建单位、法术、装备、传奇、横版战场或符文。单位支持英雄和专属分类。
卡库载入会复制双语文字、费用、战力、符能、印版和画师资料，原卡保持独立。
配图只截取整张卡图中可见的区域，无法还原被印刷元素遮住的原始插画。

中文和 English 分别编辑。效果支持换行、`**加粗**`、`_斜体_`、
`{{图标或关键词}}`，也兼容卡库英文的 `[Keyword]`、`:rb_…:` 标记。
长效果默认自动缩小字号；最小字号仍放不下会显示提示。

图片支持添加多张、移动、缩放、旋转、透明度、裁剪、复制、隐藏、锁定、排序。
图片默认在卡框下方，可切到卡框上方、文字下方。
手机预览支持拖动配图、两指缩放旋转，各种变换也有数值和按钮操作。
可放大预览并返回编辑，编辑面板独立滚动；使用 VisualViewport 跟随键盘高度。
单张上传限制 20 MB，图片等比例缩小到最长边 2400 像素，GIF 使用第一帧。
作品最多 30 个图层；PNG 默认两倍尺寸（竖版 1490 × 2080，横版 2080 × 1490）。

## 保存和实现

浏览器 IndexedDB `rune.cardmaker.v1` 的 works/assets/meta 存储作品、配图和当前作品编号。
修改后 800 ms 自动保存，切换作品前强制保存；每次保存是跨三个存储区的原子事务。
写入串行排队，作品副本共享不可变图片，删除时仅清理没有剩余作品引用的图片。
图片只在首次保存时写入；文本和图层变换保存不会反复写入图片内容。
未编辑的初始空白页不占作品库；删除最后一件作品后保持空库，刷新不会重新创建空白作品。
不增加任何数据库表、云端写入或登录要求。
卡图 CDN 没有公开跨域像素读取权限，因此使用同源 `GET /api/cardmaker/image?url=…`：
Cloudflare Pages Function 与本机 Vite 共用实现，只接受本站卡库使用的三个公开 CDN，
限制图片类型、大小、超时及重定向。静态 file 模式需卡图本身允许 CORS，否则上传配图。

JSON 导出包含完整双语文档、所有变换以及内嵌 PNG 配图。
导入先校验版本、类型、有限数值、裁剪和图片，重新生成作品/图片/图层 ID，
避免覆盖本机已有作品。JSON 上限 90 MB，图片数据上限 80 MB。

界面使用 vue-konva；卡框与文字使用共享 Canvas 渲染函数，PNG 使用同一组函数，
不包含选择边框。字体、卡框和所有配图准备完成后才允许 PNG 导出。
60 步撤销/重做只记录文档，保留被历史引用的图片直到当前会话结束。
页面和字体按需加载，首页不下载工坊的中文字体或 Konva。

资源来源、字体许可证和字体替代说明见 `public/cardmaker/SOURCES.md`。

## 验证

```sh
pnpm run build
pnpm run verify:cardmaker
pnpm run verify:cardmaker-ui
```

浏览器验收使用本地卡库/图片夹具，检查双语、撤销重做、图层、锁定、裁剪、
PNG 尺寸和预览一致性、JSON 往返、刷新恢复、作品库、全部模板及移动端手势。
使用安装的 Chromium，也可通过 `CHROME_PATH` 指定浏览器。截图保存到 `/tmp/rune-cardmaker-ui-*`。
