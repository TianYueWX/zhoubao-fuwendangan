## 使用方式

1. 结算页选择卡牌和目标区域，再添加或拖动卡牌。点“连接箭头”，依次选两张牌；点已有箭头可编辑，说明可不填。
2. 每次布置好一个步骤，手动保存快照；在历史面板填写步骤说明和停留秒数。演示使用这些快照播放。
3. 点“导出动画”，选择 GIF 或 MP4，勾选和排序步骤，预览后生成文件。导出窗口中的调整不改动原历史。
4. 周报进入对应分析页面，通过显示数量选“全部”；地域另有“全部城市”和“全部英雄”。搜索先查完整明细，再按所选数量展示。
