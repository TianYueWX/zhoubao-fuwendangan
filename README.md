# 符文档案 · 周报

Riftbound(符文战场)城市挑战赛赛事数据的纯前端分析工具,按期发行的奥术档案周刊。无需后端、无数据库:上传赛事数据包,即刻获得**真实胜率驱动的 Tier 分级、传奇域对分布、万金油单卡、Combo 羁绊、地域地图与带卡图的卡组浏览器**的完整 Meta 洞察。

- **纯前端单页**:构建产物本地双击即可使用(卡图需联网加载,离线自动降级为文字色块)
- **默认部署目标**:Cloudflare Pages
- 技术栈:Vite + Vue 3 + TypeScript + ECharts + Tailwind CSS

---

## 数据准备

在「数据导入」页上传以下文件(**前 3 个必需**,后 3 个可选但强烈推荐;点任意上传框可一次多选,按文件名关键词自动识别槽位):

### 必需(基础分析)

| 槽位 | 文件 | 说明 |
|---|---|---|
| 📊 赛事卡组 | `*decks_data*.csv` | 列:`activityName` / `shopProvince` / `date` / `finalRanking` / `playerName` / `hero` / `TTS_code` |
| 🃏 卡牌基础 | `cards_base*.csv` | 全量卡表:费用/类型/颜色/地域/力量/禁卡标记等 971+ 张 |
| 🖨️ 卡牌印刷 | `card_prints*.csv` | 编号 × 印刷版本关联(含卡图 CDN) |

### 可选(增强能力)

| 槽位 | 文件 | 解锁 |
|---|---|---|
| 🏅 名次胜场 | `*rank_data*.json` | **真实胜率**(瑞士轮胜场/轮次)、按胜场排序、城市×英雄胜率热力、Tier 以胜率为核心 |
| 🏪 赛事门店 | `*shop_data*.json` | **精确城市/门店/赛事规模**,替代正则猜城(实测 24/24 场全命中) |
| 🖼️ 卡组缓存 | `*decks_cache*.json` | **卡牌图片索引**(约 40MB,解析需 1-2 秒),卡组浏览器完整卡图 |

> 轮次推断:每场赛事总轮次 = 该场 `winCount` 最大值(128 人 → 7 轮瑞士轮,已验证)。
> 胜率 = Σ胜场 / Σ轮次,为加权口径。

## 功能一览(侧边栏导航)

| 视图 | 内容 |
|---|---|
| 📥 数据导入 | 6 槽位上传、数据质量报告(匹配率)、赛事城市映射修正 |
| 📊 Meta 总览 | KPI 行;**英雄 Tier List(S/A/B/C 自动评级)**;热度×强度象限散点(均值参考线,点击下钻);**传奇域对(Domain Identity)分布环图** |
| 🏆 英雄拆解 | 全英雄搜索选择器(不截断);含真实胜率指标卡;Jaccard 流派自动聚类;核心卡 Top20 携带率条形表 |
| 🌟 单卡分析 | 万金油 Top60:类型/颜色域/费用筛选、卡图缩略、禁卡标记、全环境携带率对照 Δpp 列 |
| 🔗 Combo 羁绊 | Lift 提升度挖掘(剔除符文卡);**Lift 与携带率门槛实时滑块**;行点击弹出卡对详情解读 |
| ⚔️ 传奇对比 | **同一传奇的卡组横向对比**:名次优先排序(最佳 = 短时间窗口内最好成绩),向下取前 1/2/3/5/10 名或勾选自由组合;卡牌矩阵着色(共通/部分/独有)展示构筑差异;周次过滤 |
| 🗺️ 地域差异 | 城市×英雄出场率(点击城市全局过滤);城市站点气泡地图;省份热度地图;**Top8率/真实胜率双模式热力图**;赛事一览表(门店/规模/轮次) |
| 🃏 卡组浏览器 | 名次/英雄筛选 + 胜场排序;行点击抽屉展开**完整构筑(按类型分组 + 卡图缩略)+ 一键复制 TTS 码** |

### 全局联动

- 顶部过滤条:**Top 阈值 / 英雄 / 城市 / 日期范围**作用于所有视图,实时显示过滤后样本数
- 图表点击下钻:总览散点点英雄 → 英雄拆解并过滤;地域柱状图点城市 → 全局城市过滤
- Tier 综合分 = 胜率分位×0.55 + Top8率分位×0.20 + 出场率分位×0.25(S ≥ p85 / A ≥ p60 / B ≥ p30);样本 <15 或无胜率数据不评级
- 浅色/深色/跟随系统三档主题,图表即时重绘

## 开发与部署

```bash
npm install
npm run dev        # 本地开发
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # 预览构建产物
```

Cloudflare Pages 配置:框架预设 None,构建命令 `npm run build`,输出目录 `dist`。

数据仅供竞技参考 · Riot Games 与本工具无关。
